DINARY 계정 및 데이터 삭제

최종 수정·시행 2026년 10월 25일

앱을 다시 설치하지 않아도 계정 삭제를 요청할 수 있습니다. 계정은 유지하고 일부 데이터만 지우려면 아래 안내를 확인해 주세요.

웹에서 삭제 요청하기

계정 삭제 요청 이메일 보내기

메일 앱이 열리지 않으면 contact.dinary@gmail.com으로 제목을 「DINARY 계정 삭제 요청」으로 하여 보내 주세요. DINARY 닉네임과 로그인 방식(구글 또는 애플)을 알려 주세요. 가능하면 로그인에 사용하는 이메일 주소에서 보내 주세요.

비밀번호, 인증번호, 신분증은 보내지 마세요. Apple의 「나의 이메일 가리기」를 사용했거나 로그인 이메일을 사용할 수 없으면 알려 주세요. 다른 사람의 계정이 삭제되지 않도록 운영자가 필요한 본인 확인 방법을 안내합니다. 본인 확인 및 처리 결과는 이메일로 회신합니다. 확인 전에 계정을 삭제하지 않습니다.

앱에서 바로 삭제하기

기록장 메뉴에서 내 프로필 → 회원 탈퇴 → 탈퇴를 선택하세요. Apple로 가입한 경우 소유자 확인이나 연결 해제 절차가 추가로 필요할 수 있습니다. 앱에서 확인이나 삭제를 완료할 수 없으면 위 이메일로 요청해 주세요.

삭제되는 정보

본인 확인과 서버의 삭제 절차가 완료되면 계정, 프로필, 내가 남긴 식사 기록과 사진, 위시리스트, 게시판·갤러리·친구 소식의 게시물과 댓글, 추천 이용 기록, 푸시 토큰을 삭제하는 절차를 진행합니다. 네트워크·파일 정리·계정 연결 해제에 실패하면 완료되지 않을 수 있으므로 결과를 확인해 주세요. 삭제가 완료된 계정과 기록은 서비스에서 복구할 수 없습니다.

연인 기록장에서 상대가 직접 작성한 기록, 다른 이용자의 독립적인 기록에서 사용하는 자료와 외부로 저장·공유한 사본은 본인의 탈퇴로 모두 회수되지 않습니다. 연인 연결 해제만으로 기존 기록이 삭제되는 것은 아닙니다. 기기에 직접 저장하거나 다른 앱으로 공유한 사진은 해당 기기나 앱에서 직접 지워 주세요.

앱에서 탈퇴할 때 이 기기의 업로드 대기 기록·사진과 추천 대기 정보를 정리하고 로그인·위젯 표시를 해제하도록 처리합니다. 기기 오류로 정리가 완료되지 않으면 앱 데이터를 지우거나 앱을 삭제해 주세요. 웹에서 삭제한 뒤 다른 기기에 남아 있는 대기 사진은 해당 기기에서 DINARY를 삭제하여 지울 수 있습니다. 삭제 요청 이메일은 본인 확인·요청 처리·회신에 사용하며, 해당 메일의 삭제도 같은 주소로 요청할 수 있습니다. 백업·로그·이미 전달된 알림 등은 계정과 같은 시점에 모두 삭제되는 것은 아닙니다. 자세한 범위는 개인정보 처리방침 6조를 확인해 주세요.

계정은 유지하고 일부 데이터만 삭제하기

탈퇴하지 않고도 앱에서 직접 지울 수 있습니다. 식사 기록은 기록 상세 → 기록 삭제, 위시는 위시 상세의 삭제나 묶음 삭제, 게시판·친구 소식의 글과 댓글은 해당 항목의 메뉴 → 삭제, 갤러리 사진은 메뉴 → 갤러리에서 내리기를 선택하세요. 랭킹 참여는 내계정 › 랭킹 참여에서 끌 수 있습니다. 지운 항목은 서비스에서 복구할 수 없습니다.

앱에서 지울 수 없는 정보(추천 이용 기록, 프로필 정보 등)나 특정 데이터의 삭제는 데이터 삭제 요청 이메일로 요청해 주세요. 제목은 「DINARY 데이터 삭제 요청」, 닉네임·로그인 방식과 지우고 싶은 정보를 적어 주세요. 본인 확인 뒤 해당 데이터를 삭제하고 결과를 회신합니다. 계정과 나머지 기록은 유지됩니다.

개별 항목을 지워도 추천 이용 기록·문의 메일·신고와 운영 기록은 함께 지워지지 않으며, 별도로 요청할 수 있습니다. 백업·로그는 삭제 시점에 바로 지워지지 않고 서비스 제공자의 보관 주기가 지나면 삭제됩니다.

연결 해제와 기기 삭제의 차이

구글·애플 계정 설정에서 DINARY 연결을 해제하거나 앱만 삭제해도 서버의 DINARY 계정과 기록은 자동으로 삭제되지 않습니다. 서버 계정 삭제를 원하면 앱의 회원 탈퇴나 위 이메일 요청 절차를 이용해 주세요.
