DINARY 개인정보 처리방침

최종 수정 2026년 10월 21일

DINARY(이하 "서비스")는 개인이 만든 식사 기록 서비스입니다. 아래 내용은 서비스가 어떤 정보를 받아 어떻게 쓰는지 정리한 것입니다.

1. 수집하는 정보

가. 로그인할 때 — 구글 또는 애플로 로그인하면 해당 계정의 고유 식별자와 이메일 주소를 받습니다. 구글은 이름과 프로필 사진 주소를, 애플은 첫 로그인 때 한 번 이름을 함께 줍니다. 애플의 「나의 이메일 가리기」를 고르면 애플이 만든 대리 주소만 받습니다. 전화번호·성별·생년월일은 받지 않습니다.

나. 프로필 — 이용자가 정한 닉네임, 프로필 사진, 대표 캐릭터.

다. 서비스를 쓰면서 — 이용자가 직접 남긴 식당 이름, 주소, 가게 위치, 메모, 별점, 가격, 메뉴, 사진, 방문 날짜, 라벨, 가고 싶은 곳 목록(묶음, 담아 온 링크 주소 포함)이 저장됩니다. 사진은 900px 로 줄여 다시 저장하므로 원본의 촬영 위치 정보(EXIF)는 남지 않습니다.

라. 함께 쓰는 기능 — 친구 관계와 친한 친구 목록, 숨기기·차단 목록, 연인 기록장의 구성원과 사귄 날, 게시판의 글·댓글·투표·공감, 갤러리에 올린 사진·좋아요·댓글, 신고 내용이 저장됩니다.

마. 방문 인증 — 사진을 찍는 순간 기기의 위치를 한 번 읽어 근처 식당 후보를 찾습니다. 이때 좌표 자체는 저장하지 않고, 위치 정확도(미터)와 인증이 통과한 시각만 기록에 남습니다.

바. 가고 싶은 곳 알림(선택) — 알림과 「항상」 위치를 허용하면, 담아둔 곳 중 가까운 20곳을 기기의 지오펜스로 등록해 50m 안에 들어오면 알림을 띄웁니다. 백그라운드 위치는 기기 안에서만 판단하며 서버로 보내지 않습니다. 기기 설정에서 언제든 끌 수 있습니다.

사. 추천과 지도 — 「지금 뭐 먹지」나 지도에서 주변 가게를 찾을 때 지금 위치나 지도에서 누른 자리의 좌표를 서버 함수로 보냅니다. 좌표는 그 요청에만 쓰고 저장하지 않습니다. 추천을 고르는 데 쓰려고 보여 준 후보, 누른 동작(자세히 보기·담기·길찾기·방문 확인 등), 동네 이름과 거리(미터)를 이용 기록으로 남깁니다.

아. 기기 안에만 — 아직 올리지 못한 기록 대기열과 앱 설정은 기기에만 저장됩니다.

2. 쓰는 곳

받은 정보는 이용자의 기록을 저장하고 보여주는 일, 이용자가 고른 사람과 기록을 나누는 일, 추천을 낫게 하는 일, 신고 처리와 부정 이용 방지에만 씁니다. 광고에 쓰지 않고, 이용자를 분석해 다른 곳에 넘기거나 팔지 않습니다.

3. 공개 범위

기록은 기본적으로 나만 봅니다. 아래처럼 이용자가 직접 고른 경우에만 다른 사람에게 보입니다.

가. 연인 기록장 — 함께 쓰는 상대가 그 기록장의 기록·사진·가고 싶은 곳·한 줄 메모를 봅니다. 개인 기록장의 기록은 상대에게 보이지 않습니다. 연결을 끊으면 두 사람 모두 읽기만 할 수 있습니다.

나. 친구 소식 — 올린 기록은 이용자가 고른 대상(친구 전체 또는 친한 친구)에게 보입니다. 메모와 위치 정확도는 보이지 않습니다.

다. 게시판·갤러리 — 게시판의 글·댓글과 붙인 기록(가게, 사진), 갤러리에 올린 사진 한 장과 그 가게·동네는 로그인한 모든 이용자에게 보입니다. 갤러리에 사진을 올려도 그 기록의 나머지는 공개되지 않습니다.

라. 랭킹 — 참여를 켠 경우에만 닉네임과 인증된 방문 수 같은 숫자가 보입니다. 기록 내용은 보이지 않습니다.

마. 프로필 — 닉네임, 프로필 사진, 대표 캐릭터는 로그인한 이용자에게 보입니다.

로그인하지 않은 사람은 아무것도 볼 수 없습니다. 숨기거나 차단한 사람의 기록·글은 내 화면에서 빠집니다. 운영자는 신고 처리를 위해 신고되거나 숨김 처리된 글·댓글·사진을 볼 수 있습니다.

4. 맡겨 둔 곳

가. 서비스 운영 — 데이터베이스, 사진 보관, 로그인, 서버 함수에 Supabase(서울 리전)를, 이 안내 페이지 호스팅에 GitHub Pages 를, 앱 업데이트 배포에 Expo 를 씁니다. 로그인에는 구글과 애플을 씁니다.

나. 외부 API — 서버 함수가 아래 API 를 부릅니다. 검색어나 좌표, 주소만 보내고 이용자 계정 정보는 넘기지 않습니다.

· 카카오 로컬 API — 주소·좌표 변환, 가게 검색, 주변 추천 후보
· 기상청 단기예보(공공데이터포털) — 추천 탭의 날씨. 좌표를 예보 격자로 바꾼 값만 보냅니다
· 행정안전부 도로명주소(juso.go.kr) — 길게 누른 자리의 건물 찾기
· 국토교통부 VWorld — 건물 경계

다. 기기에서 바로 — 지도 표시에 NAVER 지도를 씁니다. 링크로 가고 싶은 곳을 담으면 그 링크의 제목을 해당 사이트(유튜브, 블로그 등)에서 읽어 옵니다.

각 사업자는 자신의 정책에 따라 정보를 처리합니다.

5. 보관과 삭제

기록은 이용자가 지우기 전까지 보관합니다. 프로필 화면의 회원 탈퇴를 누르면 계정과 프로필, 기록, 사진, 가고 싶은 곳, 게시판·갤러리·친구 소식에 올린 글과 댓글, 추천 이용 기록이 모두 삭제되며 되돌릴 수 없습니다. 연인 기록장에서는 내가 남긴 기록이 지워지고, 상대가 남긴 기록은 상대에게 남습니다. 개별 기록은 언제든 지울 수 있습니다.

6. 이용자의 권리

언제든 본인 기록을 보고, 고치고, 내려받고, 지울 수 있습니다. 구글·애플 계정 연결 해제는 각 서비스의 계정 설정(구글 「서드 파티 앱」, 애플 「Apple로 로그인」)에서도 할 수 있습니다.
